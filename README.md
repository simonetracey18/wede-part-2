Pretty and Clawed Website css 

This project focuses on improving the visual design and user experience of the Pretty and Clawed nail salon website by adding Cascading Style Sheets (CSS). The website was originally created using HTML, and CSS was implemented in Part 2 to transform the website into a more modern, professional, and visually appealing beauty brand website.

Changes Made

Created an External CSS File

A separate stylesheet called `style.css` was created to manage the website’s design and layout. This helped organise the website better and made the code easier to maintain.

 2. Added Modern Styling

The website design was improved using:

* Soft pastel colour palettes
* Elegant typography
* Modern spacing and alignment
* Hover effects on navigation links and buttons
* Rounded corners and shadows for service cards

3. Improved Navigation Bar

The navigation menu was styled to look cleaner and more professional. Hover effects were added to improve user interaction and make the website feel more modern.

4. Enhanced Homepage Design

The homepage was redesigned with:

* A hero section
* Styled headings and paragraphs
* Call-to-action buttons
* Better image presentation
* Improved text layout and readability

5. Added Responsive Design

Media queries were used to make the website responsive on smaller screens such as mobile phones and tablets.

6. Improved Service Section

The services section was redesigned using CSS Grid layout to display service cards neatly and professionally.

7. Styled Buttons and Footer

Custom button designs and footer styling were added to create a luxury beauty salon aesthetic.

Technologies Used

* HTML5
* CSS3
* Google Fonts

Outcome

The CSS enhancements successfully transformed the website from a basic HTML layout into a professional-looking nail salon website with a feminine and luxury aesthetic. The updated design improves user experience, visual appeal, and overall website presentation.
